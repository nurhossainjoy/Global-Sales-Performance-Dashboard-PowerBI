# Sales Performance Dashboard (Power BI)

## Project Overview

This project presents an interactive **Sales Performance Dashboard** built using **Microsoft Power BI**.
The objective of the dashboard is to analyze sales data and generate actionable insights related to revenue, customer distribution, regional performance, and order patterns.

The dashboard helps decision-makers quickly understand key business metrics and identify trends that can support strategic planning.

---

## Key Features

* Sales performance overview
* Revenue analysis
* Regional sales comparison
* Customer distribution insights
* Order trend visualization
* Interactive filters and slicers

---

## Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Business Intelligence
* Data Analytics

---

## Dataset

The dataset used in this project includes information such as:

* Sales
* Revenue
* Customer
* Region
* Orders

The dataset is used to perform exploratory data analysis and build interactive dashboards.

---

## Dashboard Insights

The dashboard provides insights such as:

* Which regions generate the highest revenue
* Sales trends across different periods
* Customer contribution to total sales
* Order distribution patterns

---

## How to Use

1. Download the `.pbix` file from the repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Explore the interactive dashboard and filters.
